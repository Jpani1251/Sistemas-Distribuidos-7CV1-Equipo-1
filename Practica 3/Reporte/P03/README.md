## Resumen del Proyecto y Entregables
Esta práctica comprende el análisis comparativo de los modelos de servicio (IaaS, PaaS, SaaS, FaaS, CaaS, DBaaS, AIaaS y XaaS) y los esquemas de despliegue en la nube, evaluando el impacto de la apertura de regiones en México (Querétaro). 

Asimismo, se documenta la creación práctica de un recurso de Infraestructura como Servicio (IaaS) mediante una Máquina Virtual Ubuntu Server ejecutada en **Microsoft Azure (Región Mexico Central)**, exponiendo un servidor HTTP Nginx público y verificando su desasignación preventiva.
